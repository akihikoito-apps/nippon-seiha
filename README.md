# 日本制覇

ふたりで47都道府県をめぐる記録帳です。

白い日本地図の上で、行ったことのある県を **到来（薄紅）**、やりきった県を **制覇（朱）** に塗り分けていきます。それぞれ日付を残せて、「記録」からこれまでの軌跡を日付順に読み返せます。

**公開先** → https://akihikoito-apps.github.io/nippon-seiha/

iPhoneなら、Safariで開いて共有ボタンから **「ホーム画面に追加」** すると、ふつうのアプリと同じように使えます。

## 使い方

| | |
|---|---|
| 県をさわる | 到来・制覇を選ぶシートが開きます |
| エリアのボタン | 関東・四国などを選ぶと、そこにズームしてボタンが県名に変わります |
| 記録を見る | 到来と制覇を日付順に並べた一覧 |

## 作り

- HTML 1枚（`index.html`）だけで動きます。ビルドもサーバーも要りません
- 記録は **各自の端末の中（localStorage）** に保存されます
- 置き場は GitHub Pages（`main` ブランチの直下）

### これから

いまは端末ごとに記録が分かれています。**ふたりで同じ記録を共有する仕組みは、これから入れます。**

## 地図データについて

地図は Geolonia「[SVG Map of Japan](https://github.com/geolonia/japanese-prefectures)」を使っています。Wikipedia「[日本地図.svg](https://ja.wikipedia.org/wiki/%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB:%E6%97%A5%E6%9C%AC%E5%9C%B0%E5%9B%B3.svg)」に基づくもので、ライセンスは **GFDL** です。

縦横比の都合で、小笠原諸島などの一部の離島は地図から省略されています（元データの仕様）。
